# PlannerShop Web

Gestionale multi-tenant per attività commerciali (clienti, catalogo, vendite, agenda, statistiche).

- **Backend**: Java 21 + Spring Boot 3 (`backend/`)
- **Frontend**: Angular + PrimeNG (`frontend/`)
- **Deploy**: Docker Compose (`docker/`)
